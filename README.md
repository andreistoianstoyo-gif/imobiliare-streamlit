Steps to run the application(ONLY for backend verification)

!!YOU MUST HAVE PYTHON INSTALLED!!

Follow these steps in your terminal:

Step 1: Install the required libraries
If you don't have them installed yet, run the following command:
python -m pip install streamlit pandas plotly

Step 2: Navigate to the project folder
Ensure that your terminal is open in the folder where you saved `app.py` and `housing.csv`.

Step 3: Run the application
Execute the following command:
python -m streamlit run app.py

What happens next?
1. Streamlit will launch a local server.
2. A page will automatically open in your browser (usually at http://localhost:8501).
3. You will see interactive charts where you can hover over data points to view details or zoom in.
